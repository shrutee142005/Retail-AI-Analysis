## Features

- Revenue forecasting visualization
- Customer search and filtering
- Customer segmentation across four clusters
- Cluster-wise business recommendations
- Interactive charts and business insights

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **Backend:** Python, Flask
- **Database:** SQLite

## Project Structure

- `frontend/` — Dashboard interface and frontend assets
- `api/` — Flask API endpoints
- `data/` — Local SQLite database
- `dashboard/` — Dashboard screenshots

## Run Locally

1. Install the required Python packages from `requirements.txt`.
2. Start the Flask API using your project's Python environment.
3. Open `frontend/index.html` in your browser.
4. Ensure the frontend API URL points to the running Flask server.
