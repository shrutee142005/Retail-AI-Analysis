# Retail AI Analysis

A retail analytics dashboard built to explore revenue forecasting, customer segmentation, and AI-based business recommendations.

## Features
- Revenue forecasting dashboard
- Customer search and filtering
- Customer segmentation across four clusters
- Cluster-wise business recommendations
- Interactive charts and insights

## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask
- SQLite
- Chart.js

## Project Structure
- `frontend/` — Dashboard UI
- `api/` — Flask API
- `data/` — Local database

## Run Locally
1. Start the Flask API from the `api` folder using your project's Python setup.
2. Open the frontend in your browser.
3. Ensure the frontend API URL points to the running Flask server.

## Note
This project is currently configured for local development. Deployment configuration may be required to run it online.
